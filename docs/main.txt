做一个 macos 应用, 主要功能是使用一个日历组件展示各个 agent 应用的历史用量, 5 小时限额周期, 周限额周期, 月限额周期的覆盖范围和用量情况.
用量获取路径:

  1. 你需要先尝试从本地的 Cursor, chatgpt, agy 等 CLI 中获取各种周期的用量
  2. 如果行不通, 就想办法获取这些平台是否提供 API 查询用量的能力
  3. 如果还不行就尝试从这些平台的 web 中获取接口, 然后让用户在环境变量中设置用户名.密码, 去构造请求获取这些数据.

将获取方式总结成 markdown  表格保存到 source_method.md

然后让我补充缺失的信息, 直到数据都能获取后, 再继续页面的开发.
